# snippetvault

Self-hosted code snippet manager for developer teams.

## Requirements

Node.js 16+

    npm install
    cd client && npm install

Copy `.env.example` to `.env` and set `JWT_SECRET`.

## Running

    npm run dev

Server runs on port 3001. Client on port 5173.

## Testing

    npm test
